# DogDrip.Con Uploader v1.0.1

v1.0.0 이후 게시글 작성과 이미지 편집, 태그 입력 편의성을 중심으로 기능을 확장했습니다.

## WYSIWYG 게시글 에디터

- 실제 결과와 유사한 형태로 본문을 작성하는 WYSIWYG 에디터 추가
- HTML 원본 보기 및 직접 편집 기능 제공
- 링크, 가로줄, 이미지 삽입 도구 제공
- 붙여 넣은 하이퍼링크 유지
- 링크 우클릭 메뉴에서 표시 텍스트와 URL 수정 지원

## 이미지 삽입 및 편집

- URL을 이용한 원격 이미지 삽입과 설명 텍스트 설정 지원
- 이미지 우클릭 메뉴에서 설명, URL, 가로·세로 크기 수정 지원
- 이미지 삽입·수정 화면에 자동 미리보기 제공
- 원본 크기, 적용 크기, 미리보기 배율 표시
- 가로 또는 세로 한쪽만 지정하는 크기 설정 지원
- 크기를 입력하지 않으면 원본 크기 사용
- `원본 비율 맞춤` 옵션으로 반대편 크기 자동 계산
- 중복된 `http://` 및 `https://` 주소 자동 정리

## 태그 입력

- 쉼표로 구분한 태그를 배지 형태로 표시
- 각 태그에 개별 삭제용 `X` 버튼 제공
- 한글 조합 입력을 고려한 태그 변환 처리

## 이미지 배치 옵션

- 파일 이름
- 파일 이름 역순
- 수정된 날짜
- 수정된 날짜 역순
- 폴더 검사 결과를 이미지별 한 줄로 표시하고 첫 번째 파일을 메인 이미지로 지정

## UI 및 사용성

- DogDrip.Con Uploader 전용 로고와 프로그램 아이콘 적용
- 개드립넷의 색상 조합을 활용한 UI 개선
- 화면 크기에 맞춘 프로그램 창 크기 조정
- 최초 실행 시 빠른 시작 가이드 제공
- 상단에 버전 정보와 `Guide` 메뉴 표시
- 개드립콘 등록 주소를 복구하는 `기본 페이지` 버튼 제공
- 로그 우클릭 메뉴의 로그 지우기 기능과 호버 스크롤바 제공
- 주요 팝업과 안내 메시지를 프로그램 창 중앙에 표시

## 설정 및 데이터 이전

- 사이트 입력 항목을 직접 수정하는 매칭 설정 화면 제공
- 구성 파일 및 브라우저 프로필을 `dogdrip-con` 이름으로 변경
- 기존 `dogcon` 구성 파일과 브라우저 프로필 자동 이전
- 기존 로그인 상태와 사용자 설정 유지
