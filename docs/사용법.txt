개드립콘 폴더 업로더 사용법
============================

1. 업로드할 이미지 파일을 한 폴더에 저장합니다.
   - 기본값인 "파일 이름순"에서는 이름순의 첫 파일이 메인 이미지입니다.
   - image2.png는 image10.png보다 앞에 오는 자연 정렬을 사용합니다.
   - 기존처럼 1.png, 2.png ... 규칙을 강제하려면 "숫자 파일명 (1~50)"을 선택합니다.
   - PNG, JPG, JPEG, GIF, WEBP를 지원합니다.
   - 번호는 중간에 빠지거나 중복되면 안 됩니다.

2. dogcon-folder-uploader.exe를 실행하고 "폴더 선택"을 누릅니다.

   필요한 경우 앱의 "게시글 내용" 칸에 본문을 작성합니다.
   - 게시글 제목과 판매 포인트도 앱에서 입력할 수 있습니다.
   - 판매 포인트는 숫자로 입력합니다.
   - 하이퍼링크: [표시할 텍스트](https://example.com)
   - HTTP/HTTPS 주소만 링크로 변환됩니다.
   - 가로줄: 별도의 한 줄에 --- 만 입력합니다.
   - 원격 이미지: ![대체 텍스트](https://example.com/image.png)
   - 이미지 크기 지정: ![대체 텍스트](https://example.com/image.png){가로, 세로}
   - 예시: ![샘플](https://example.com/image.png){320, 200}
   - 이미지 문법은 HTTP/HTTPS URL만 지원하며, 로컬 파일은 개드립 에디터에서 직접 첨부합니다.
   - 태그는 태그 입력란에 쉼표로 구분해서 작성합니다.

3. "1. 전용 브라우저 열기"를 누릅니다.
   - 처음 한 번은 개드립 사이트에 직접 로그인합니다.
   - 앱은 쿠키나 비밀번호를 읽거나 별도 저장하지 않습니다.

4. 브라우저에서 개드립콘 등록/수정 페이지를 엽니다.

5. 앱으로 돌아와 "2. 파일 자동 배치"를 누릅니다.
   - 이미지와 작성한 게시글 내용이 함께 채워집니다.

6. 브라우저에서 이미지, 제목, 판매 포인트를 확인한 뒤 등록 버튼을 직접 누릅니다.

설정 및 로그인 프로필
---------------------
- EXE 옆에 dogcon-uploader-settings.json과 dogcon-browser-profile 폴더가 생성됩니다.
- 페이지 필드 매칭은 dogcon-uploader.ini에 저장됩니다.
- 사이트의 input name이나 CSS 선택자가 바뀌면 앱의 "매칭 설정"에서 수정할 수 있습니다.
- target_host는 열린 탭 중 자동 배치 대상 사이트를 구분하는 안전장치입니다.
- 완전 초기화하려면 브라우저를 닫고 위 두 항목을 삭제하면 됩니다.

주의
----
- 사이트의 HTML 필드명이 바뀌면 프로그램 업데이트가 필요할 수 있습니다.
