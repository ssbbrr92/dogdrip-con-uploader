# DogDrip.Con Uploader v1.1.1

## 에디터 툴바 개선

- 굵게, 기울임, 밑줄과 왼쪽·가운데·오른쪽 정렬 버튼을 추가했습니다.
- 8px부터 48px까지 글자 크기를 선택하거나 직접 입력할 수 있습니다.
- 폰트 크기 목록에서 각 항목을 실제 픽셀 크기로 미리 볼 수 있습니다.
- 선택한 텍스트의 서식에 따라 툴바 버튼과 글자 크기 표시가 자동으로 동기화됩니다.
- 링크, 가로줄, 이미지 삽입 기능을 아이콘 툴바로 정리했습니다.

## 키보드 및 편집 안정성

- `Ctrl+A/B/I/U/C/X/V/Z/Y` 단축키를 지원합니다.
- 한글 IME 상태에서도 물리 키코드를 판별해 단축키가 동작합니다.
- 에디터를 클릭했을 때 입력 커서가 표시되지 않던 포커스 문제를 수정했습니다.

## UI 및 사용성 개선

- 폰트 크기 팝다운을 앱 디자인에 맞는 전용 목록으로 변경했습니다.
- 팝다운이 화면 좌측 상단에 나타나거나 즉시 닫히던 문제를 수정했습니다.
- 드롭다운과 로그 스크롤바의 배색 및 형태를 정리했습니다.
- 메인 화면의 불필요한 휠 이동과 화면 흔들림을 줄였습니다.
- 툴팁이 클릭 후 다시 나타나거나 창 최소화 후 남는 문제를 수정했습니다.
- 사용 가이드의 단축키 안내와 팝업 높이를 최신 기능에 맞게 갱신했습니다.
