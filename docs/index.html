DOWNLOAD

설치 없이 바로 실행

  1. GitHub Releases에서 EXE 다운로드최신 릴리스의 DogDrip.Con-Uploader-*.exe를 받습니다.
  2. 원하는 폴더에서 실행설치 과정이 없는 Portable 프로그램입니다. 설정과 브라우저 프로필은 EXE 주변에 저장됩니다.
  3. SmartScreen 안내 확인코드 서명이 없는 무료 비공식 앱이라 최초 실행 시 경고가 나타날 수 있습니다. GitHub 릴리스의 SHA256과 내려받은 파일을 비교하세요.
공용 PC에서는 사용하지 마세요

전용 브라우저 프로필에는 로그인 상태가 남을 수 있습니다. 개인 PC에서만 사용하고, 프로필 폴더를 공유하지 마세요.

STEP 01

업로드할 이미지 선택

폴더 하나를 선택하면 지원되는 이미지가 정렬 기준에 따라 최대 50개까지 배치됩니다.

지원 형식

PNG, JPG, JPEG, GIF, WebP 파일을 지원합니다.

배치 순서

파일 이름·파일 이름 역순·수정된 날짜·수정된 날짜 역순으로 정렬할 수 있습니다.

메인 이미지

정렬 결과의 첫 번째 파일이 메인 이미지가 됩니다. 폴더 검사 결과는 파일마다 한 줄로 표시됩니다.

STEP 02

게시글 정보 입력

비워 둔 선택 항목은 등록 페이지의 기존 값을 바꾸지 않습니다.

등록 페이지 주소

주소를 잘못 입력했다면 기본 페이지 버튼으로 기본 등록 주소를 복원합니다.

게시글 제목·판매 포인트

필요할 때만 입력합니다. 판매 포인트는 숫자로 입력하세요.

태그

쉼표를 입력하면 배지로 변환됩니다. 배지 오른쪽 X를 누르면 해당 태그만 삭제됩니다.

WYSIWYG EDITOR

보이는 모습 그대로 본문 작성

14 px⌄

굵게 표시할 텍스트와 링크를 바로 확인할 수 있습니다.

가운데 정렬도 즉시 반영됩니다.

제공 기능

  • 굵게, 기울임, 밑줄
  • 왼쪽, 가운데, 오른쪽 정렬
  • 8~48px 글자 크기 및 직접 입력
  • 링크·가로줄·이미지 삽입
  • 이미지 URL, 설명, 크기와 원본 비율 수정
  • HTML 보기 전환
이미지와 링크 편집

삽입된 이미지나 링크를 우클릭하면 현재 UI와 같은 색상의 수정 메뉴가 열립니다. 빈 영역의 우클릭 메뉴에서는 붙여넣기도 사용할 수 있습니다.

SETTINGS

설정과 로컬 데이터

dogdrip-con-uploader-settings.json화면 입력값과 사용자 설정
dogdrip-con-uploader.ini사이트 필드명·선택자·target_host 매칭
dogdrip-con-browser-profile/전용 브라우저 로그인 프로필

이전 dogcon 이름의 구성 파일이 발견되면 새 dogdrip-con 이름으로 이전하여 기존 설정을 이어서 사용합니다. 화면에 보이는 작업 로그는 별도 로그 파일로 저장하지 않습니다.

TROUBLESHOOTING

자주 묻는 문제

SmartScreen에서 알 수 없는 앱으로 표시됩니다.

무료 비공식 앱이므로 유료 코드 서명이 적용되지 않았습니다. 반드시 이 저장소의 Releases에서 받고, 릴리스에 표시된 SHA256과 파일을 비교하세요.

이미지가 예상 순서와 다르게 배치됩니다.

폴더 검사 전에 배치 순서를 확인하세요. 파일 이름 정렬은 image2가 image10보다 먼저 오도록 자연 정렬을 사용합니다.

자동 배치가 갑자기 동작하지 않습니다.

사이트의 입력 필드 이름이나 구조가 바뀌었을 수 있습니다. 매칭 설정에서 값을 확인하고, 최신 릴리스가 있는지 살펴보세요.

전용 브라우저 기록을 초기화하고 싶습니다.

프로그램과 브라우저를 모두 종료한 뒤 dogdrip-con-browser-profile 폴더를 삭제하면 됩니다. 저장된 로그인 상태도 함께 사라집니다.
