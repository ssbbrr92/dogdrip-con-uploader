# DogDrip.Con Uploader Lite v1.0.1

## 로컬 재적용

`tools/package-lite.ps1`을 실행하면 아래 고정 폴더가 동일한 이름으로 갱신됩니다.

`dist/DogDrip.Con-Uploader-Lite-v1.0.1/`

Chrome의 `압축해제된 확장 프로그램을 로드합니다`에서 이 폴더를 한 번 선택한 뒤에는 확장 관리 화면에서 새로고침만 누르면 됩니다.

기존 Python/EXE 버전과 별도로 배포하는 Chrome Manifest V3 확장 프로그램입니다. 확장 아이콘을 누르면 브라우저 우측 사이드 패널로 열리며, 현재 브라우저의 로그인 세션을 그대로 사용해 개드립콘 등록 페이지에 이미지와 게시글 정보를 배치합니다. 최종 등록 버튼은 자동으로 누르지 않습니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 우측 상단의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `lite-extension` 폴더를 선택합니다.

ZIP 배포본은 먼저 압축을 푼 뒤 위 폴더를 선택해야 합니다.

## 사용법

1. 확장 프로그램에서 이미지 폴더와 배치 순서를 선택합니다.
2. 제목, 판매 포인트, 본문 HTML, 태그를 필요에 따라 입력합니다.
3. **등록 페이지 열기**를 누르고 개드립넷에 로그인합니다.
4. 등록 페이지가 열린 상태에서 확장 프로그램을 다시 열어 **이미지와 내용 채우기**를 누릅니다.
5. 페이지에서 결과를 확인한 뒤 최종 등록 버튼을 직접 누릅니다.

사이드 패널이 보이지 않으면 Chrome 툴바에서 확장 프로그램 아이콘을 고정한 뒤 `DogDrip.Con Uploader Lite` 아이콘을 누르세요. 패널의 좌우 위치는 Chrome의 사이드 패널 설정을 따릅니다.

## Lite판의 범위

- PNG, JPG, JPEG, GIF, WebP 최대 50개
- 파일 이름/수정된 날짜, 정순/역순 정렬
- 제목, 판매 포인트, 본문 HTML, 태그 입력
- CKEditor 4.22.1 Full 기반 인라인 WYSIWYG 본문 편집
- 등록 페이지 자동 배치
- 입력 내용은 `chrome.storage.local`에 저장
- 선택한 이미지 자체와 작업 로그는 저장하지 않음

브라우저 보안 정책상 프로그램을 다시 열면 이미지 폴더는 다시 선택해야 합니다. 사이트의 입력 필드 이름이 변경되면 확장 프로그램 코드 업데이트가 필요합니다.

## CKEditor 및 라이선스

본문 편집기는 CKEditor 4.22.1 Full 공식 배포본을 확장 프로그램 내부에 포함합니다. CKEditor 4.22.1은 CKSource가 GPL 2+, LGPL 2.1+ 또는 MPL 1.1 중 선택할 수 있도록 배포한 오픈소스 버전이며, 이 확장 프로그램은 LGPL 2.1 이상 조건을 선택합니다. 원문은 `vendor/ckeditor/LICENSE.md`에서 확인할 수 있습니다.

CKEditor 4 일반 버전은 2023년 6월 지원이 종료되어 이후 보안 업데이트가 제공되지 않습니다. 이 확장 프로그램은 원격 CKEditor 코드나 유료 CKEditor 4 LTS를 사용하지 않습니다.

## 개드립넷 이미지

사이드 패널의 프로필 이미지는 패키지에 포함하지 않고 개드립넷의 공식 URL을 실행 중 직접 참조합니다.

확장 프로그램과 사이드 패널에는 프로젝트에서 직접 제작한 기하학형 `D` 아이콘을 사용합니다.
